# Calls to action and (optional) promotion

Most posts are value posts with a **soft CTA**. Promotion is optional and limited.
This file explains how to do both well.

## Soft CTAs: the default

A soft CTA asks nothing of the reader beyond using the idea. The post delivers
the full value: the actual checklist, steps, framework, or lesson.

Patterns (always rewrite them in the user's voice):

| Pattern | Example |
|---|---|
| Tie it to a moment in their week | "Run this 5-point check before your next Monday priorities meeting." |
| Small experiment | "Try just step 2 at your next team check-in. Notice what changes." |
| Save for later | "Save this for your next quarterly planning session." |
| Reflection | "Which of these does your team skip most often?" |
| Add to it | "What would you add as #6?" |
| Share it | "Send this to the person who runs your weekly ops meeting." |

Use what you learned in the interview about the audience's week (Round 2 Q3) so
the moment feels real: a sales pipeline review, a 1:1, sprint planning, month-end
close, a Friday wrap-up.

**Never** use: "comment [WORD] to get it", "comment for access", "DM me for the
link", or "follow for part 2" cliffhangers that hold back the useful part.

## Ask posts: optional, limited, and still useful

Only if `offers.md` lists something and the ask cadence isn't "never".

**Spacing rule:** at least **3 soft-CTA posts** come before every ask post,
counting across profile and Page in calendar order. The user's ask cadence can
make asks rarer, but never more frequent than that.

Check this every time you build the calendar and every time the user asks for an
ad-hoc promotional post. If an ask would come too early, offer to:
- schedule it after the next value posts, or
- turn it into a soft-CTA value post now, with the ask coming later

**What an ask post looks like:**
1. It still teaches or shares something genuinely useful that stands on its own.
2. Then it mentions the offer once, plainly, with a direct link: "If you want the editable version of this checklist, it's here: [link]" or "I help [audience] with [result]. If that's you, here's my calendar: [link]."
3. No fake urgency, scarcity, numbers, or testimonials. Only use deadlines and results the user has confirmed are real.

**Where the link goes:** directly in the post, in the first comment, or in the
profile's Featured section, whichever the user prefers. Never put it behind
"comment to get it".

## A gentle runway for a new offer

When the user adds something new (a service, free resource, booking link, or
event), plan the runway around their cadence. For example, with a cadence of
"1 ask after 3+ value posts":

1. Value post on the problem it solves (soft CTA)
2. Value post with a practical how-to from the topic (soft CTA)
3. Story or lesson related to it (soft CTA)
4. Ask post: useful content, plus a single mention of the offer and its link
5. Back to value posts. The next ask comes no sooner than 3 more soft-CTA posts later.

## Tracking (only if they want it)

Add UTM tags to links in ask posts so they can see which posts drive clicks:

```
https://their-site.com/page?utm_source=linkedin&utm_medium=social&utm_campaign=<offer-slug>&utm_content=<post-date>
```

Use `utm_medium=organic_personal` vs `organic_page` to compare destinations. Log
clicks or sign-ups in `results.md` when they share numbers.

If they ask for help building an opt-in page or email follow-up, help in their
voice. But only when asked. That's outside this skill's core job.
